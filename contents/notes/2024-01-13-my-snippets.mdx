### 2.4. その他

- 先読みアサーション

  ```c
  X(?=Y)
  ```

  パターン X に対してパターン Y が続く場合のみ X がマッチする。

  ```c
  // 例えば次の場合……
  .+(?=@)

  // 'local' にのみマッチする ('@' にはマッチしない)
  local@example.com
  ^^^^^
  ```

  ```shell
  | jq
  ```


### 3.10. magick (ImageMagick 7)

- 画像を変換してリサイズなどを行う

  ```shell
  magick ./briefcase.svg -resize 10x10 ./out/briefcase.png
         ^^^^^^^^^^^^^^^ ^^^^^^^^^^^^^ ^^^^^^^^^^^^^^^^^^^
         入力ファイル    リサイズ指定  出力ファイル

  オプション:
    -resize 10x10                   画像を 10x10px にリサイズする
    -background none                背景を透明にする
    -density 1200                   SVG を高解像度でラスタライズする
    -size 16x16                     キャンバスを 16x16px にする
    xc:none                         透明なキャンバスを作成
    -fill '#496369'                 塗りつぶし色を指定
    -draw 'roundrectangle ...'      角丸の四角形を描画
    -gravity center                 画像を中央に配置
    -composite                      画像を重ね合わせる
  ```

  ```shell
  # e.g. ウェブサイト用の各種アイコンファイルを作成する例
  # - PWA 用 icon-192x192.png (角丸)
  # - PWA 用 icon-512x512.png (角丸)
  # - Apple デバイス用 apple-icon.png (非角丸 180x180px)
  # - favicon.ico (角丸 16 / 32 / 48 / 64px)

  # librsvg2-dev をインストールする
  # SVG を扱うための開発用パッケージ
  sudo apt install -y librsvg2-dev pkg-config

  # ImageMagick 7 をインストールする
  # https://imagemagick.org/install-source/
  git clone --depth 1 --branch 7.1.2-30 https://github.com/ImageMagick/ImageMagick.git ImageMagick-7.1.2-30
  cd ImageMagick-7.1.2-30
  ./configure --with-rsvg
  make
  sudo make install
  sudo ldconfig /usr/local/lib

  /usr/local/bin/magick logo: logo.gif
  # -> 現在ディレクトリへ logo.gif が出力されていれば OK

  magick --version
  # -> PATH が通っていることを確認できたら OK

  # SVG 素材を準備して配置する
  # 例) https://lucide.dev > briefcase (鞄) アイコン

  # 出力先ディレクトリを作成する
  mkdir -p out

  # ここまでのディレクトリ構成
  $ tree --dirsfirst
  .
  ├── out
  └── briefcase.svg

  # magick コマンドで各ファイルを生成する
  # icon-192x192.png
  magick -background none -density 1200 ./briefcase.svg -resize 150x150 /tmp/icon-192.png && \
  magick -size 192x192 xc:none -fill '#496369' -draw 'roundrectangle 0,0 191,191 30,30' /tmp/bg-192.png && \
  magick /tmp/bg-192.png /tmp/icon-192.png -gravity center -composite ./out/icon-192x192.png

  # icon-512x512.png
  magick -background none -density 1200 ./briefcase.svg -resize 400x400 /tmp/icon-512.png && \
  magick -size 512x512 xc:none -fill '#496369' -draw 'roundrectangle 0,0 511,511 80,80' /tmp/bg-512.png && \
  magick /tmp/bg-512.png /tmp/icon-512.png -gravity center -composite ./out/icon-512x512.png

  # apple-icon.png
  magick -background none -density 1200 ./briefcase.svg -resize 140x140 /tmp/icon-180.png && \
  magick -size 180x180 xc:'#496369' /tmp/icon-180.png -gravity center -composite ./out/apple-icon.png

  # favicon.ico
  magick -background none -density 1200 ./briefcase.svg -resize 10x10 /tmp/icon-16.png && \
  magick -size 16x16 xc:none -fill '#496369' -draw 'roundrectangle 0,0 15,15 3,3' /tmp/bg-16.png && \
  magick /tmp/bg-16.png /tmp/icon-16.png -gravity center -composite /tmp/favicon-16.png && \
  magick -background none -density 1200 ./briefcase.svg -resize 20x20 /tmp/icon-32.png && \
  magick -size 32x32 xc:none -fill '#496369' -draw 'roundrectangle 0,0 31,31 5,5' /tmp/bg-32.png && \
  magick /tmp/bg-32.png /tmp/icon-32.png -gravity center -composite /tmp/favicon-32.png && \
  magick -background none -density 1200 ./briefcase.svg -resize 30x30 /tmp/icon-48.png && \
  magick -size 48x48 xc:none -fill '#496369' -draw 'roundrectangle 0,0 47,47 8,8' /tmp/bg-48.png && \
  magick /tmp/bg-48.png /tmp/icon-48.png -gravity center -composite /tmp/favicon-48.png && \
  magick -background none -density 1200 ./briefcase.svg -resize 40x40 /tmp/icon-64.png && \
  magick -size 64x64 xc:none -fill '#496369' -draw 'roundrectangle 0,0 63,63 10,10' /tmp/bg-64.png && \
  magick /tmp/bg-64.png /tmp/icon-64.png -gravity center -composite /tmp/favicon-64.png && \
  magick /tmp/favicon-16.png /tmp/favicon-32.png /tmp/favicon-48.png /tmp/favicon-64.png ./out/favicon.ico

  # 作成された
  $ tree --dirsfirst
  .
  ├── out
  │   ├── apple-icon.png
  │   ├── favicon.ico
  │   ├── icon-192x192.png
  │   └── icon-512x512.png
  └── briefcase.svg
  ```

### 5.2. ⚠️Git の操作を取り消す

```shell
# 1. git reflog で操作履歴を出力する
$ git reflog
02f11b7 HEAD@{0}: reset: moving to 02f11b7                               # 現在のコミット (HEAD)
0488e28 HEAD@{1}: merge develop: Merge made by the 'recursive' strategy. # 1 つ前のコミット
...

# 2. 戻りたいコミットを指定して git reset する
# 「1 つ前」に戻す場合は「HEAD@{n}」へ 1 を指定する
# ディレクトリの内容が書き換わるので注意
$ git reset --hard HEAD@{1}

# コミットのハッシュを指定してもよい
$ git reset --hard 0488e28

# ステージング状態へ戻す場合は --soft を指定する
$ git reset --soft HEAD@{1}
```

### 5.4. キャッシュを削除する

[kem198/dotfiles](https://github.com/kem198/dotfiles?tab=readme-ov-file#git-%E3%81%AE%E3%82%AD%E3%83%A3%E3%83%83%E3%82%B7%E3%83%A5%E5%89%8A%E9%99%A4%E6%89%8B%E9%A0%86) にも記載しているもの。

- グローバルな除外設定 (`.gitignore_global` など) を設定する前にコミットをしてしまった。
- 過去に追跡対象としてコミットしたファイルを `.gitignore` の追跡対象外へ追加する。
- `.gitignore` を整理したので追跡対象の設定が問題ないか確認したい。

これらに該当する場合は Git のキャッシュ削除が必要になる。

```shell
# 1. cd
cd fuga

# 2. Git のキャッシュをすべてのファイルから削除する
git rm --cached -r .

# 3. 全てのファイルをステージングする
git add -vA

# 4. コミット対象のファイルが変更を加えたファイルのみであるか確認する
git status -s

# 5. コミットする
git commit -m 'commit comments'
```

- [.gitignoreに記載したのに反映されない件 #Git - Qiita](https://qiita.com/fuwamaki/items/3ed021163e50beab7154)
- [Git - git-rm Documentation](https://git-scm.com/docs/git-rm)
  - [-r](https://git-scm.com/docs/git-rm#Documentation/git-rm.txt--r)
  - [--cached](https://git-scm.com/docs/git-rm#Documentation/git-rm.txt---cached)

## 8. VS Code

### 8.1. 保存時の設定を無効化する

```json
{
  "files.insertFinalNewline": false,
  "files.trimFinalNewlines": false,
  "files.trimTrailingWhitespace": false
}
```

これを `ワークスペース/.vscode/settings.json` へ記述すると、[ユーザー設定で行われている](https://github.com/kem198/dotfiles/blob/0defd6780a2505a590646184708781cf54fd9553/config/Code/User/settings.json#L22-L24) 下記の記述を無効化できる。

- 保存時に新規行を挿入 (`files.insertFinalNewline`)
- 保存時に不要行を除去 (`files.trimFinalNewlines`)
- 保存時に行末のスペース記号を削除 (`files.trimTrailingWhitespace`)

他者が作成したコードをそのまま保存したいときに配置する。
